# HomeDishPicker 家常菜抽签系统

一个用于练习前端基础、Codex、Git、README 和版本控制的小项目。

## 项目目标

制作一个网页版家常菜随机抽签系统，帮助用户快速决定今天吃什么。

## 第一版功能

- 展示家常菜候选列表
- 点击按钮随机抽取一道菜
- 显示抽签结果
- 支持重复抽取

## 第二版功能

- 抽签时显示菜名滚动，最后定格到抽中的菜
- 输入冰箱现有食材，根据食材推荐可做菜品
- 抽签时优先从匹配食材的菜品中抽选
- 支持添加自己会做的菜到抽签库
- 自定义菜品会保存在当前浏览器中
- 每道菜都提供小红书教程搜索入口

## 第三版功能

- 添加菜品时，输入常见菜名会自动补充需要的食材
- 新增“随机发现一道菜”，用于尝试抽签库以外的新菜灵感
- 新菜灵感和抽签结果都提供小红书教程搜索入口
- 抽签库按菜品分类折叠展示，减少页面滚动长度
- 冰箱食材匹配结果会在抽签库卡片中显示

## 当前版本

v3 已完成食材推荐、自定义菜品、自动补充食材、滚动抽签、新菜灵感和折叠分类展示。页面可以直接在浏览器中运行，不需要安装依赖。

## 后续计划

### 近期功能

- 支持编辑和删除自定义菜品，避免添加错了以后只能清空浏览器数据。
- 支持“不重复抽取”模式，一轮抽完前不重复出现同一道菜。
- 增加抽签历史记录，记录最近抽中过哪些菜和对应时间。
- 给冰箱食材增加快捷标签，常用食材可以一键添加或清除。
- 给“随机发现一道菜”增加分类筛选，例如快手菜、肉菜、素菜、主食、汤羹。

### 数据管理

- 支持导入和导出抽签库，方便换电脑、发给手机或备份。
- 支持重置为默认抽签库，方便学习和测试。
- 支持为每道菜补充备注，例如口味、难度、预计耗时。
- 支持给菜品添加“已做过”“想尝试”“常吃”等状态。

### 教程与推荐

- 给每道菜保存固定教程链接，而不只是跳转到小红书搜索页。
- 增加多个教程来源入口，例如小红书、B 站、下厨房。
- 根据冰箱食材完整度显示推荐等级，例如“食材齐全”“缺 1 个食材”。
- 后续如果引入后端，再考虑接入真实搜索或 AI 推荐能力。

### 项目工程化

- 增加基础测试，检查随机抽签、食材匹配、添加菜品等核心逻辑。
- 拆分 JavaScript 文件，让数据、渲染、业务逻辑更清晰。
- 使用 GitHub Pages 部署，让手机可以直接通过网址访问。
- 增加版本更新记录，持续练习 README、Git commit 和项目管理。
